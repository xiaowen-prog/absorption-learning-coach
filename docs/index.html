问题 · Problem

常见做法为什么学不进

冷测与答案倾倒看起来高效，却常常只留下「好像听懂了」的错觉。

!

冷测过早

材料还没扫过，就凭口述摘要闭卷提问。缺口被误判成「记性差」，挫败感先于学习发生。

≠

答案倾倒

贴出完整范例骨架再要求「按这个重做」。学习者会复制表面结构，判断力与回忆力几乎没练到。

方法 · Method

五步吸收环

一次处理一块材料。优先预测、判断与闭卷回忆；格式由教练决定，减少选择负担。

1

拆解 Split

把来源拆成：结论 / 叙事线 / 关键决策 / 可复用方法 / 金句引用。

2

价值 Value

用一句话说清：它为什么对学习者当前目标重要。

3

闭卷回忆 Closed-book recall

合上笔记再测。若尚未扫过原文，先给短骨架或留出自读时间，再开测。

4

迁移 Transfer

同一观念放进新场景：会不会用，比能不能复述更重要。

5

反驳 Rebuttal（可选）

作者可能错在哪、漏了什么。锻炼批判而不只是认同。

分层 · Tiers

讲解深度 × 难度自适应

卡住再升级；答得清就迁移与反驳。疲劳时降档，而不是硬扛。

解释层级

Light

轻量

一行结论 + 一个熟悉例子。适合已有底子、只需对齐口径时。

Medium

中等

每个术语旁附白话释义；加一次复述检查，确认不是「听过」而已。

Full

完整

完整拆解，必要时配图示，再进入测验。始终先给一行结论，并用同一条贯穿例。

难度自适应（自评）

高吸收 · 回答清晰

直接上迁移 / 反驳题，拉开判断与迁移肌肉。

中等 · 术语发糊

点出术语，问含义 + 一个极小例子，再继续。

低吸收 · 多次「忘了」

降档：只回看错过的点，降低同时负荷。

疲劳 / 需要休息

自动降档，仍可学轻量项；明确需要休息时提醒暂停，避免无效硬磨。

规则 · Quiz Rules

测验怎么问，才练到吸收

规则比题量重要。下面四条是硬约束，避免「看起来在学、其实在抄」。

  • ✓
    一次一题，选合适形式 判断、简答、场景应用均可；由教练决定格式，不问学习者「你想用哪种」。
  • ✓
    只诊缺口，不贴完整骨架逼重做 答完后给简短差距诊断。绝不粘贴整份模范答案再要求「按这个重写」——那会诱导复制。
  • ✓
    错题换新场景再探 漏掉的点稍后放进新情境重测，而不是立刻原题重做。
  • ✓
    结束时给短吸收报告 缺口列表 + 粗略吸收比例；不因一次侥幸答对就抬高评价。
  • ✓
    疲劳自动降档 说累、读不动时降低负荷；仍可推进轻量项，但不要冷停或无效硬扛。
活模型 · Living Model

持续更新的学习者状态

教练不是固定脚本，而是根据吸收度、缺口、疲劳与有效形式，随时调整。

持续追踪

活的学习者模型

每篇材料的吸收度、待再探的缺口、疲劳信号、哪些表达形式真正有效——写进模型，据此改下一轮教练动作。

每周一次

周复盘

回顾对话，修订方法；把可沉淀的方法变更写入长期记忆，避免同一弯路反复踩。

刻意不做的事

  • 在专长缺口上从大而全的基础课重开
  • 用答案倾倒替代学习
  • 当前材料闭卷仍弱时，并行塞入大量新文章
